# Generator-parole
Problema rezolvată: Parolele slabe sunt una dintre cele mai frecvente cauze ale conturilor compromise. Aplicația ajută la crearea și evaluarea parolelor sigure. Funcții: Generator de parole: lungime 8–64 de caractere, la alegere litere mici, litere mari, cifre și simboluri, cu generare criptografic sigură și copiere într-un clic.
